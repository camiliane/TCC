# TCC
Códigos utilizados para o meu TCC em Bioinformática:

**Investigação do perfil de expressão do CFTR em subtipos de câncer gástrico: análise de expressão diferencial, co-expressão e vias biológicas**

- Extração e controle de qualidade de dados de RNA-seq de plataformas públicas (TCGA, TCGABiolinkGUI)

- Análise de Expressão Diferencial, construção de redes de co-expressão e ontologia gênica do gene CFTR (R, EdgeR, CEMiTool, clusterProfiler)

Artigo publicado:

CFTR interactome may impact gastric cancer: an in silico system-level coexpression analysis. **Journal of Biochemical and Clinical Genetics**. DOI: [10.24911/JBCGenetics.11-2222](https://jbcgenetics.com/articles/10.24911/JBCGenetics.11-2222)
